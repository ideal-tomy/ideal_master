## 🛠️ 技術的実装詳細

### React.memoの適用パターン

```tsx
// Before: 通常のコンポーネント
const AICapabilitySection: React.FC<Props> = ({ title, contents }) => {
  // 毎回再レンダリング
};

// After: メモ化されたコンポーネント
const AICapabilitySection: React.FC<Props> = memo(({ title, contents }) => {
  // props変更時のみ再レンダリング
});

export default memo(AICapabilitySection);
```

### useMemo・useCallbackの最適化パターン

```tsx
// Before: 毎回新しいオブジェクト・関数を生成
const ServiceCard = ({ id, title }) => {
  const path = servicePathMap[id] || id;
  const handleClick = () => navigate(`/services/${path}`);
  // ...
};

// After: メモ化されたオブジェクト・関数
const ServiceCard = memo(({ id, title }) => {
  const path = useMemo(() => servicePathMap[id] || id, [id]);
  const handleClick = useCallback(() => {
    navigate(`/services/${path}`);
  }, [navigate, path]);
  // ...
});
```

### Intersection Observerの活用

```tsx
// 画像遅延読み込みの実装
const { ref, shouldLoadImage } = useImageLazyLoading({

return (

    )}

);
```
