## Next.jsプロジェクト 宇宙背景反映手順

Next.js 14 (App Router) プロジェクトに、Viteプロジェクトから宇宙背景アニメーション（Three.jsベース）を移植し、サイト全体に適用する手順です。

### 1. 関連コンポーネントのコピー

以下のコンポーネントファイルをViteプロジェクトの `src/components/common/` から Next.jsプロジェクトの `ideal-next/src/components/common/` へコピーしました。

*   `SpaceBackground.tsx`: Three.jsを使用したメインの宇宙背景アニメーションコンポーネント。
*   `FallbackSpaceBackground.tsx`: WebGL非対応環境向けのCSSアニメーションによる代替背景コンポーネント。

### 2. Client Component化

Next.js App Routerでクライアントサイドのインタラクションを持つコンポーネントとして動作させるため、コピーした各ファイルの先頭に `"use client";` ディレクティブを追加しました。

*   `ideal-next/src/components/common/SpaceBackground.tsx`
*   `ideal-next/src/components/common/FallbackSpaceBackground.tsx`

### 3. グローバルレイアウト (`layout.tsx`) の編集

サイト全体に背景を適用するため、`ideal-next/src/app/layout.tsx` を以下のように編集しました。

*   必要なコンポーネントをインポート:
    *   `import { Box } from '@chakra-ui/react';`
    *   `import SpaceBackground from '@/components/common/SpaceBackground';`
*   `metadata` を更新（サイトタイトル、説明）。
*   `html` タグの `lang` 属性を `"ja"` に変更し、スタイル（`minHeight: '100vh', overflow: 'hidden'`）を追加。
*   `body` タグにスタイル（`minHeight: '100vh', display: 'flex', flexDirection: 'column', position: 'relative', overflow: 'hidden'`）を追加。
*   `Providers` コンポーネントの内側に、以下の要素を配置:
    *   静的なグラデーション背景用の `Box`:
        *   `position="fixed"`, `top/left/right/bottom={0}`
        *   `bg="linear-gradient(180deg, #000235 0%, #000010 100%)"`
        *   `zIndex={-2}`
    *   `SpaceBackground` コンポーネントをラップする `Box`:
        *   `position="fixed"`, `top/left/right/bottom={0}`
        *   `zIndex={-1}`
        *   内部に `<SpaceBackground height="100vh" position="fixed" zIndex={-1} />` を配置。
    *   メインコンテンツ（`Header`, `children`, `Footer`）をラップする `Box`:
        *   `display="flex"`, `flexDirection="column"`, `minHeight="100vh"`
        *   `position="relative"`, `zIndex={0}`
        *   `Header`
        *   メインコンテンツ表示用の `Box` (`as="main"`, `flex="1"`, `pt`調整, `position="relative"`, `zIndex={1}`)
        *   `Footer`

### 4. TypeScriptエラー対応 (OrbitControls)

`ideal-next/src/components/common/SpaceBackground.tsx` 内で、`OrbitControls` のインポートに起因するTypeScriptエラー (`モジュール 'three/examples/jsm/controls/OrbitControls' またはそれに対応する型宣言が見つかりません。`) が発生しました。
`OrbitControls` は当該コンポーネント内で `enabled = false` となっており、実際には使用されていなかったため、エラー解消を優先し、関連する以下の行をコメントアウトしました。

*   `import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls';`
*   `const controls = new OrbitControls(camera, renderer.domElement);`
*   `controls.enabled = false;`

### 5. 動作確認

上記対応後、Next.js開発サーバーを再起動し、ブラウザで `http://localhost:3000` を表示。
サイト全体の背景として宇宙アニメーションが正しく表示されることを確認しました。
