# エラーループ打破チェックリスト

## 1. React Router の整理
- [ ] プロジェクトで React Router は本当に必要か判断  
  - ✅ 不要：全て Next.js Router（`next/link`, `next/navigation`）に統一 → `react-router-dom` をアンインストール  
  - ⚠️ 必要：専用の Client Component（例：`app/router/page.tsx`）に切り出し、`BrowserRouter` でのみラップ  

## 2. Next.js Router の徹底活用
- [ ] `<Link>` は必ず `import Link from 'next/link'` を使う  
- [ ] ルーティング用フックは `import { useRouter } from 'next/navigation'`  
- [ ] `react-router-dom` の `Link` / `Route` / `BrowserRouter` は必要な箇所以外全部削除 or 別プロジェクトに切り離す
